# Green lake environment v1

Unused green-mountain alternative generated with the built-in image tool on 2026-10-14.

Source: `assets-src/parallax-green-lake-v1/distant-mountains.png`.
Reference: `assets-src/parallax-alpine-lake-v1/distant-mountains.png`.

Rounded grassy mint and jade mountains replace the blue snowy peaks. The other layers
are reused from the alpine lake set: clouds and pine islands. No gameplay code or
runtime assets are changed.

The source is a 1536 x 1024 RGBA PNG. Soft translucent green fringes remain outside
the main silhouettes, similar to the style reference; check against the intended sky
before runtime optimisation. Typecheck and production build pass.

Open [preview.html](preview.html) for desktop and portrait compositions with layer toggles.
The sky and water are illustrative CSS. Exact generation instructions are in
[prompt.txt](prompt.txt). Integration and optimisation happen separately.
