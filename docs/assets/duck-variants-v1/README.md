# Duck variants v1

Each is RGBA 2048×256: eight 256×256 cells, six poses and two empty cells. Same frame order as `src/art/duckSprite.ts`. Generated art may vary slightly from the original silhouette; check in-game debug collisions when integrating. These optional assets are not loaded by gameplay yet.
